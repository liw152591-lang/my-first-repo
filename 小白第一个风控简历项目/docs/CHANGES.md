## 原有内容的保留

本地 `archive/before_cleanup/` 保存整理前的脚本、Notebook、README、旧 `.ipynb` 和所有根目录结果文件。归档默认 Git 忽略，方便回溯个人学习过程。

## 代码改动

| 位置 | 改动 | 原因及影响 |
|---|---|---|
| 导入与路径 | 用项目文件位置定位数据，集中输出目录；脚本使用无界面绘图 | 不依赖个人环境名或工作目录，不弹出大量窗口 |
| 警告 | 移除全局屏蔽，仅过滤已核查的库弃用、日期类型探测及内部赋值提示 | 评分独立校验通过；保留模型收敛与数值计算警告 |
| 第 2 节 | 增加 ID、字段、标签、缺失、重复与年龄/工龄异常检查 | 只记录并导出事实，没有改样本 |
| 第 3 节 | 数值特征分布不再包含 ID 和标签 | 避免将标识和目标当成连续业务特征 |
| 第 7/10 节 | 固定特征顺序、明确 p 值并列处理、增加逐步筛选循环保护 | 原库列顺序可能变化；多个 p 值可能数值下溢为 0。本次最终变量集合不变 |
| 第 9 节 | VIF 计算加入截距列 | 改成常用含截距诊断口径；VIF 数值变化，但未据此新增删除变量 |
| 第 12 节 | 纠正 odds 注释，去除 300—900 固定范围说法 | 公式与模型本来一致，纠正文案，不截断评分 |
| 第 15 节 | 等宽分组包含最左边界 | 防止边界恰好等于最低分时遗漏样本 |
| 第 16 节 | 用 ROC 唯一概率阈值计算并绘制 KS | 正确处理同概率样本，本次 KS 不变 |
| 第 17 节 | 训练/验证使用训练集确定的十分位边界 | 修正跨集合比较口径，验证集人数和 Lift 改变，不代表模型改善 |
| 第 19 节 | 增加评分绝对误差验证；输出模拟规则实际通过率和事件率 | 相关系数接近 1 不足以验证公式；同分样本使通过率不必恰好 70% |
| 第 20 节 | PSI 使用固定训练集等宽边界、两端无限延伸，平滑后归一化 | 不让实际样本极值改变比较基准；只解释分布差异 |
| 导出 | 增加指标、分箱、系数、质量表、评级、阈值和运行信息 | README 数字可追溯，不依赖 Notebook 中的历史输出 |
| 命名/绘图 | 修正 valid 拼写、章节编号、标签口径，增加图顶留白 | 提升可读性，避免事件率与标题重叠 |

仍保留按章节编排的学习脚本，没有重构为复杂框架。后续扩展与核心建模在 Notebook 中明确分开。
