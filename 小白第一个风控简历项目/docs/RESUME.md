# 简历与面试说明

## 可直接使用的核心项目描述

**基于 WOE 与逻辑回归的贷款风险评分卡｜个人学习项目**  
技术：Python、pandas、scorecardpy、scikit-learn、statsmodels

- 基于 Kaggle 58,645 条有标签贷款样本，开展数据类型、缺失值及变量分布分析，按标签分层划分训练集与验证集。
- 在训练集完成自动分箱与 WOE 编码，结合相关性分析、VIF 诊断及逐步逻辑回归筛选 9 个变量，构建逻辑回归模型；本地验证集 AUC 0.9091、KS 0.6820。
- 将模型系数转换为基准分 600、PDO 50 的评分卡，生成变量分箱分值表与样本评分，完成特征处理、概率预测到评分转换的完整流程。

这版聚焦原有第 12 节及之前的核心工作。简历日期填写真实学习时间；仓库链接填写实际发布地址。

## 理解扩展分析后可替换的一条描述

> 通过固定训练集分箱边界，分析验证集分组事件率、Lift 和评级分布，并计算样本间分数 PSI，区分模型区分度、分布变化与实际审批策略验证的边界。

只在能够解释这些指标、分箱规则与局限之后使用；不需要为了增加简历关键词而写入所有扩展内容。

## 60 秒介绍

这是我第一个完整的评分卡学习项目，使用 Kaggle 合成贷款数据。我的重点是理解数据如何从原始变量转换成可解释的分数。我先做数据概览和变量分布分析，再分层划分训练集与验证集，只在训练集完成分箱和 WOE 编码。之后结合相关性、VIF 诊断和逐步逻辑回归筛选变量，最终用 9 个变量训练逻辑回归，本地验证集 AUC 约 0.909、KS 约 0.682。最后将回归系数转换成评分卡。项目没有真实业务上线，后续图表和整理有 AI 辅助；我会区分自己已理解的核心工作与仍在学习的扩展内容。

## 面试前应能解释的问题

| 问题 | 回答要点 |
|---|---|
| 为什么先划分再 WOE？ | WOE 使用标签；全量拟合会将验证标签信息带入特征处理 |
| 为什么删除贷款等级？ | 它的 WOE 与利率 WOE 相关约 0.913；保留利率减少信息重复 |
| IV、VIF、p 值是否都用于删变量？ | 相关性驱动移除贷款等级，逐步回归实施筛选；IV/VIF 只用于展示诊断 |
| 标签 1 一定是真实违约吗？ | 本项目按风险事件处理；合成数据没有真实逾期定义和时间窗口，不据此作真实 PD 承诺 |
| 600 分是什么意思？ | 基准坏/好比 1:20，p=1/21；不是“及格线”或自动审批阈值 |
| PDO=50 是什么？ | 好/坏比翻倍加 50 分，概率与分数之间是 log-odds 关系 |
| AUC 高是否代表概率准确？ | 不代表；AUC 衡量排序，还没有开展概率校准验证 |
| 为什么验证 AUC 比训练略高？ | 单次随机划分可能出现样本波动；不能单凭这一点判断泄漏或泛化极佳 |
| PSI 很低说明什么？ | 当前分数分布接近；不是时间外稳定、低坏账或策略盈利证据 |
| 异常值怎么处理？ | 新版增加质量记录，保留原始分箱基线；没有依据验证效果挑选删除规则 |
| AI 参与了哪些部分？ | 参考公开资料学习核心流程；后续评估、图表与项目整理有 AI 辅助，具体改动见 CHANGES |
